    Le dictionnaire de données énumère les données que chaque parcours enregistre ou échange, comme le fait le DAK des lignes directrices SMART de l’OMS dans sa composante 5 : un ensemble de données par étape qui les écrit ou les lit, chacun étant un modèle logique FHIR dont les éléments portent un code (TD.<data set>.DE<nn>, CodeSystem TrustDemoDataElements), une définition, une cardinalité et, lorsque le guide dispose d’une liste de codes, une liaison. La correspondance realisation de chaque modèle indique où ce guide réalise l’élément : dans un profil ou un exemple, dans la charge utile DVC de WHO SMART Trust PHW (DVCMinPreQual), ou dans un champ CWT ou COSE. Les éléments de données sont lus par la logique d’aide à la décision et comptés par les indicateurs.

    La source est dak/data-dictionary.json ; les modèles logiques du guide, les listes de codes et cette page en sont générés. Toutes les personnes et valeurs des exemples sont fictives.

    The data dictionary lists the data each journey records or exchanges, as the WHO SMART Guidelines DAK does in its component 5: one data set per step that writes or reads it, each a FHIR logical model whose elements carry a code (TD.<data set>.DE<nn>, CodeSystem TrustDemoDataElements), a definition, a cardinality and, where the guide has a code list, a binding. Each model’s mapping realisation says where this guide realises the element: in a profile or example, in the DVC payload of WHO SMART Trust PHW (DVCMinPreQual), or in a CWT or COSE field. The data elements are read by the decision-support logic and counted by the indicators.

    The source is dak/data-dictionary.json; the guide’s logical models, code lists and this page are generated from it. Every person and value in the examples is fictional.

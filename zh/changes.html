    0.1.0（ci-build）

    • 首批 L2 和 L3 内容：作为 ActorDefinition 的通用人物画像和系统行动者、用户场景，以及业务流程 J1 至 J4.1，均由工具框架源文件生成。
    • 这些旅程讲述 VaxLink 的故事（问题 #21）：Somsak SENGMANY 出生于泰法费基（XXR），生活在奥内萨（Onesa，XXK），一年后再次在泰法费基就诊。人物画像、系统参与者和故事已重新编写；业务流程已通用化（其中不含人名）。
    • 新增流程步骤：J2 将新生儿加入家庭，并将剂次保存为已报告、未验证；J3 在境外疫苗代码旁添加国家接种计划代码（未映射的产品由护士判定）；J4.0 记录持有人的同意，并附通行码和有效期；J4.1 新增本国门户的泳道，负责核验通行码、返回清单并记录每一次访问。
    • 新增示例：家庭 Group、登记 Questionnaire 及其应答、已报告和已验证的 Immunization、验证与裁定 Provenance、从产品代码到接种计划代码的 ConceptMap、示意性接种计划 PlanDefinition、ImmunizationRecommendation 和提醒 Task、四个奥内萨剂次、一份包含六个剂次的 IPS、Consent，以及两个 AuditEvent（访问已允许、通行码错误）。两个示意性代码系统分别代替 PreQual 产品 id 和国家接种计划代码。
    • New page: Journey examples, mapping each walkthrough screen and payload to its example here.

# ArchiMate — the demonstrator on the DPI-H RA

One folder per version of this IG (`version:` in `sushi-config.yaml`), as
cat-harness's `archimate-models` skill asks.

| folder | model | where it came from |
|---|---|---|
| `0.1.0/` | smart-ra's DPI-H RA model 0.3.0-draft.1, unchanged, plus the demonstrator's overlay: journeys J1 to J4.1, the people assigned to them, the Taifafeki and Onesan systems, each country's own instance of the RA building blocks its parts realize, where the two countries meet (the paper DVC, the VHL fetch) and what they share (WHO GDHCN, the SMART Trust specifications) and the RA capabilities the journeys realize; 7 views in the folder "SMART Trust demonstrator" | generated by `python3 -I tools/archimate/build.py` from `tools/archimate/overlay.py` and smart-ra at the commit in `tools/archimate/smart-ra.lock.json` |

Every element and relationship copied from smart-ra carries `overlay:base`, its IRI in smart-ra, so its page here links back to smart-ra's, and each demonstrator system's page links to the RA block it plays (cat-harness-tools#1950).

**Do not edit the model in Archi**: it is generated, and CI
(`build.py --check`) fails when the committed file is not what the build
makes. Change `tools/archimate/overlay.py`, or bump smart-ra in the lock, and
rebuild.

Published by the site build (`site:archimate`, cat-harness-tools'
`gen-archimate-pages.ts`): pages under `en/smart-trust-demo/archimate/`, data
and one SVG per view under `archimate/`. See `docs/architecture.md`.

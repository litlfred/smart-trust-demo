    Thai vaccines are fitted to the Lao schedule

    The Thai Hep B product doesn’t match anything on the Lao schedule. Chanthasone makes the clinical call, and the system works out what’s due next.

    Without this

    Countries name and package vaccines differently, so doses get missed or repeated.

    What makes it work

    Thailand’s original code is kept and the Lao code is added alongside; the schedule engine calculates what’s due.

    Ask the room

    Who should own the mapping between countries’ vaccine codes — WHO, each country, or each clinic?

    What if…

    There is no automatic match for the foreign vaccine.

    That is exactly this step. The nurse decides — and her decision could be shared so the next nurse doesn’t have to.

    Policy takeaway

    Never overwrite another country’s record: keep the original coding alongside the national one.

    Policy questions for the table

    1. M3Who owns the national core data set and the mapping between other countries’ vaccine codes and yours?
    2. M3Which code systems do you use for vaccine products, and is the licence question settled?
    3. M6Would your neighbour need this mapping too? If yes, why would you each build it?
